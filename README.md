# Consultas SQL para o TOTVS RM

Este repositório contém exemplos de consultas SQL genéricas para o sistema TOTVS RM, utilizando as tabelas padrão como PFUNC, PPESSOA, SA1, SE1, entre outras.

> ⚠️ Nenhuma query aqui contém dados sensíveis ou informações de negócios específicos de qualquer empresa.

## Objetivo

Facilitar o aprendizado, otimização de processos e entendimento das tabelas nativas do RM.

## Estrutura

As consultas estão separadas por módulos do sistema (RH, Compras, Financeiro, etc.).

## Contribuindo

Sinta-se livre para sugerir melhorias ou enviar novas consultas através de *pull requests*.
